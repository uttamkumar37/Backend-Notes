# Go Learning

Simple Go practice for backend engineering.

Start with plain `go run` before adding modules, frameworks, or extra tools.

## Folders

- `notes/` - Go learning notes and roadmap
- `practice/` - small hands-on programs

## Run The First Program

```bash
cd practice/01-basics
go run hello_backend.go
```

## Learning Order

1. Variables and types
2. Functions
3. Structs and methods
4. Slices and maps
5. Errors
6. Interfaces
7. Goroutines and channels
8. HTTP basics
9. Testing
