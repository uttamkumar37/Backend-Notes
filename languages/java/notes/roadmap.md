# Java Backend Roadmap

## Phase 1: Core Java

- Variables, types, operators
- Conditions and loops
- Methods
- Classes and objects
- Packages and imports
- Strings and arrays

## Phase 2: Practical Java

- Collections: `List`, `Set`, `Map`
- Exceptions
- File reading and writing
- Dates and time
- Basic debugging

## Phase 3: Backend Basics

- HTTP methods
- JSON
- API design
- SQL basics
- JDBC basics

## Phase 4: Real Backend Tools

Add these later, only when needed:

- Maven or Gradle
- JUnit
- Spring Boot
- Docker
- PostgreSQL
