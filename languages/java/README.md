# Java Learning

Simple Java practice for backend engineering.

This folder avoids build tools and framework structure for now. Use plain `javac` and `java` until the basics feel natural.

## Folders

- `notes/` - Java learning notes and roadmap
- `practice/` - small hands-on programs

## Run The First Program

```bash
cd practice/01-basics
javac HelloBackend.java
java HelloBackend
```

## Learning Order

1. Java syntax and types
2. Classes, objects, and methods
3. Collections
4. Exceptions
5. File handling
6. Basic HTTP concepts
7. JDBC and SQL basics
8. Testing
9. Spring Boot later, after core Java feels clear
